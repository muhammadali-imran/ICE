# Repository Structure

```text
ICE/
├── .agent/
│   ├── AGENTS.md                 Agent workflows and coding guidance
│   ├── changelog.md              History of agent-guidance changes
│   ├── future-improvements.md    Agent-facing candidate improvements
│   └── requirements.md           Agent work requirements and completion checks
├── docs/
│   ├── ARCHITECTURE.md            Component design and invariants
│   ├── ENGINE-DESIGN.md           Preserved target UCI, search, and evaluation design
│   ├── ROADMAP.md                 Planned milestones and improvements
│   ├── SETUP.md                   Build, test, and usage instructions
│   ├── SPEC.md                    Current behavior and project constraints
│   ├── STRUCTURE.md               This repository map
│   └── TEST_CASES.md              Test coverage and validation commands
├── src/
│   ├── attacks.cpp                Sliding-piece attack implementation
│   ├── attacks.h                  Attack tables and query declarations
│   ├── bitboard.h                 Bitboard helpers and masks
│   ├── board.cpp                  Position, FEN, hash, make/unmake
│   ├── board.h                    Board state and public position API
│   ├── main.cpp                   CLI entry point
│   ├── move.h                     Packed move representation
│   ├── movegen.cpp                Pseudo-legal and legal move generation
│   ├── movegen.h                  Fixed-capacity move list and API
│   ├── perft.cpp                  Perft and divide implementation
│   ├── perft.h                    Perft interface
│   ├── types.h                    Colors, pieces, squares, castling rights
│   └── zobrist.h                  Compile-time Zobrist keys
├── tests/
│   ├── attacks_test.cpp           Bitboards and piece attack behavior
│   ├── board_test.cpp             FEN, position state, and move rules
│   ├── move_test.cpp              Move packing and square naming
│   └── perft_test.cpp             Reference perft counts and divide
├── tools/                         Reserved for developer utilities
├── CMakeLists.txt                 Build targets and test registration
├── LICENSE                        Project license
└── README.md                      Project overview and quick start
```

Build output and fetched dependencies live under `build/` and are generated by
CMake; they are not source modules.

See [ARCHITECTURE.md](ARCHITECTURE.md) for dependencies and
[SPEC.md](SPEC.md) for supported behavior.
